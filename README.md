# Engleo

Strona internetowa szkoły języka angielskiego Engleo, prowadzona przez Adriannę Nawrot.

**Strona:** [engleo.pl](https://engleo.pl)

## Co zawiera

- ofertę zajęć indywidualnych i grupowych;
- informację o bezpłatnej lekcji próbnej;
- prezentację podejścia do nauki;
- formularz kontaktowy i sekcje informacyjne;
- galerię oraz responsywny interfejs.

## Technologie

- React 19
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Framer Motion
- komponenty Radix UI

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
